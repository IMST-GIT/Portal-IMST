#  GA Information Portal

Web portal informasi **General Affair** untuk menampilkan data operasional perusahaan secara terpusat dan mudah diakses.

##  Features

*  Informasi Ruang Rapat
*  Status Ketersediaan Driver
*  Status Kendaraan
*  Pengumuman
*  Dashboard informasi

## Tech Stack

* JavaScript
* Google Sheets
* Google Apps Script

##  Development

Clone repository:

```bash
git clone https://github.com/IMST-GIT/Portal-IMST.git
```

Kemudian buka `index.html` menggunakan **Live Server**.
